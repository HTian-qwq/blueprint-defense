# 收益减半版完整试玩

结果：普通战役 10 波胜利，856/856 消灭、0 漏怪、协议核心 10/10，罗丹击破。游戏内用时 1074.6 秒；15 座炮塔、38 台生产设备；完成 12/14 项科技，没有使用维什戴尔改件。

实际从新局开始，用浏览器点击、快捷键、正常暂停和 2× 按钮完成。只读取状态作记录，没有发放资源、修改生命、跳关或调用引擎步进。浏览器无 JavaScript 异常。动作中曾点到因费用或材料不足而禁用的按钮，随后正常等待生产补足；这些是操作等待超时，不是游戏报错。

实测生产了砂叶粉末、蓝铁粉末、钢制零件、密制晶体、高晶零件，以及低容、中容谷地电池；材料用于研究、改装与补给。大型研磨和封装设备需要轮流腾位置，说明原 44×32 地图生产空间不足。经济减半后初期仍能发展，后期多线并行后依然有较充裕的费用。炮塔升级带来的弹药需求、材料兑换/入库分配，比单纯攒费用更需要管理。

本次完整通关使用收益减半、44×32 地图、蓝铁矿 50 杀解锁的构建。之后按用户要求改为 64×48 地图和蓝铁冶炼科技；新版另有开局/生产/研究/地图回归，不将这次通关冒充为新版完整通关。
