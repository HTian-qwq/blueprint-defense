## 下一轮优化建议

先采集当前构建的性能和操作基线，再分项改动：

1. **加载与资源**：当前离线 HTML 约 43 MiB，完整字体约 20 MiB。先测启动时间和内存，再比较保留离线包与开发版拆资源的收益。
2. **界面更新**：检查 `src/app.js` 的定时界面刷新、重复 DOM 更新和画布绘制，优先减少未变化内容的重建。
3. **大规模生产与战斗**：测多设备、多弹幕时的帧耗时，重点看接口查找、碰撞、敌人检索和特效生命周期。
4. **操作体验**：在现有放置、批量与快捷栏交互上验证误操作、取消、冲突提示和缩放下的命中范围。

这些是待测方向，不是已确认的瓶颈。每项优化独立提交；涉及数值或玩法的调整另行确认范围。优先保留可离线使用和现有素材视觉效果。
